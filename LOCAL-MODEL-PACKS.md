# Bundled and local model packs

The Field camera automatically loads 13 bundled mission models in 26 placements from `assets/field-models/v1/`. No ZIP selection is needed on later visits. Drag to orbit, zoom with the wheel or pinch, and use Whole field, Top, Robot, or Follow. Cancel stops loading; Unload releases mission geometry; Load bundled models restores them or retries a failed download. Reset, Run, and Stop update the existing scene without downloading it again.

Versioned same-origin URLs work under the GitHub Pages repository subpath. The browser HTTP cache can reuse unchanged assets on reload. The first visit downloads 16,371,433 bytes (15.6 MiB) of individually compressed models, replacing 56,113,056 bytes (53.5 MiB) of GLB downloads. Files load one at a time with progress, size and SHA-256 checks. Failed files bypass the cache on retry. Publish changed assets in a new version directory and update `BUNDLED_MANIFEST_URL` so returning browsers do not reuse stale geometry.

The active `manifest-r3.json` preserves all placements from `manifest-r2.json`, including M03 yaw 180° about its registered mat anchor (80, 658 mm). Its source origin remains [92.0001, 16.5568, 49.96565] mm: the red pivots face home and the flag sits toward the left field edge. Placement accuracy is still approximate. The earlier manifests are retained as historical registration metadata. Their raw model URLs are not served by this release; the active loader always uses the compressed transports in r3.

## Lossless preprocessing

Every published asset has a `transport` entry naming a same-origin `.glb.gz` file and its compressed byte count and SHA-256. The original `file`, `bytes`, and `sha256` identify the unchanged decoded GLB: `file` is its logical filename, not a required HTTP download. The public tree includes only compressed model files. Original GLBs are preserved outside the publication tree and can also be recovered exactly with the command below. A background worker checks the compressed digest and decompresses it; the main thread then applies the existing GLB validation and rendering limits. Authenticating the complete compressed payload avoids hashing the much larger decoded payload again at runtime. Tests compare browser decoding against Node's independent decoder and the original digest. Geometry, colors, source registration, placements, collision behavior, and glTF extension restrictions are unchanged.

Decoding enforces encoded and expanded size limits, a bounded expansion ratio, the declared gzip output size, and gzip integrity. Native streaming decompression is preferred; a fixed-allocation fallback also checks CRC32. Cancelling a load terminates its worker. Reset, Run, and Stop reuse the prepared scene. Local ZIP import continues to use its existing validation path.

Rebuild transports with Python 3.9 or newer:

```bash
python3 tools/precompress-models.py
npm test
```

The default command verifies and reconstructs originals in memory from the checked-in transports before recompressing. It needs no separately downloaded source files. To recover all 13 exact original GLBs and optionally rebuild from them:

```bash
python3 tools/precompress-models.py --extract-to ../bioglow-originals
python3 tools/precompress-models.py --originals ../bioglow-originals
```

Extraction verifies both compressed and original SHA-256 and refuses to overwrite a different local model. Raw `.glb` files are ignored by Git. All tests run directly from compressed fixtures without an extraction step; optional local ZIP packs still contain ordinary GLBs and use the same import flow as before.

The command preserves the chosen manifest's placement and source data. Use `--manifest path/to/manifest.json --output path/to/new-manifest.json` to select a different input and output, keeping both manifests in the same asset directory. Gzip timestamps are fixed at zero; compressed output can vary with Python/zlib versions, so publish regenerated bytes and their new hashes together at new URLs. Serve `.gz` files as ordinary binary files without a `Content-Encoding: gzip` response header: the app performs decoding itself. Never put compressed bytes under the original `.glb` URLs.

Performance entries named `bioglow.models.*` expose fetch, worker preparation, validation, parsing, scene setup, and first render submission durations for diagnosis. The first render measurement includes synchronous upload/submission work, not independent GPU execution timing.

**Load local models ZIP** remains an optional replacement. The app reads that selected file locally without uploading or persisting it. Reload returns to the bundled pack. Model authors, source URLs, hashes, and conversion records are retained beside the bundled manifest. The owner confirmed distribution permission; the software license grants no additional model rights.

The robot follows the simulator's position, heading, configured dimensions, wheel motors, and arm motors. Mission mechanisms are static. Positions and starting poses in a preview pack may be approximate. Movement, collision response, and scoring still use the existing 2D simulator.

## Pack version 1

A standard, unencrypted ZIP contains `manifest.json` and one or more self-contained GLB files. Filenames are case sensitive and use ASCII letters, digits, underscore, hyphen, dot, and forward slash. Absolute paths, empty segments, `.` and `..` segments, and duplicate names are rejected. ZIP64 and split archives are unsupported.

```json
{
  "schema": "bioglow-local-model-pack",
  "version": 1,
  "title": "My local field models",
  "units": "mm",
  "assetUnits": "m",
  "assets": [{"id": "sample", "file": "models/sample.glb"}],
  "placements": [{
    "id": "sample-position",
    "asset": "sample",
    "nodes": ["sample-base"],
    "origin": [0, 0, 0],
    "position": [1000, 570, 0],
    "yaw": 0
  }]
}
```

GLBs use metres, Y up. The viewer applies a uniform 1000× unit conversion. `origin` is the source anchor in millimetres after this conversion. `position` is `[fieldX, fieldY, height]` in millimetres, measured from the mat's bottom-left. Field points map to Three.js `[fieldX, height, -fieldY]`; yaw is clockwise degrees. `nodes` selects named nodes, preserving their source world transforms; omit it to place the whole asset. `dockModel`, when set to M13, M14, or M15, follows the simulator's selected dock. Optional `dockYaw` adds a clockwise offset.

Limits: ZIP 256 MiB; individual compressed or expanded entry 96 MiB; expanded total 420 MiB; 96 entries; manifest 128 KiB; 40 assets; 64 placements. GLB metadata is limited to 8 MiB. The viewer limits the rendered placements to 4.5 million triangles and 500 meshes. These are rejection limits, not memory or frame-rate guarantees on every device.

Models must contain one embedded binary buffer. External resources, images, glTF extensions, animation and skinning are unsupported. Nonempty extension objects are rejected throughout the GLB JSON before parsing, even when extensionsUsed and extensionsRequired declarations are absent. Buffer ranges, hierarchy cycles, duplicate child nodes, malformed transforms, checksums, and declared sizes are validated. Before GLTFLoader runs, the viewer counts mesh primitives and their instances across all scenes: at most 500 primitive definitions, 500 instantiated meshes, 4.5 million instantiated triangles, 40 scenes, and 8,000 node instances per asset. This rejects small files that would expand into excessive scene objects. Decompression runs in a cancellable worker, one asset at a time, with a 20-second timeout per entry. Loading a valid replacement manifest releases the previous pack before loading its meshes. Saved dock selections apply as soon as a pack loads, including while the robot is idle.
